(`src/scenario/mmqa/runner/thalamusdb_runner/thalamusdb_runner.py`, github.com/sembench/sembench), for the
queries of the 11-query suite ThalamusDB has a form for: q2a, q3a, q3f, q6a, q6b, q6c, q7 (q1, q2b, q4 and q5
need map or summarise operators it does not have). Tables follow SemBench's ThalamusDB setup: `movies` =
`lizzy_caplan_text_data`, `tampa_airport` = `tampa_international_airport`, `images` with absolute paths.
